## 取舍与技术债

一个主 Agent 与有界工作流，不是多个自主 Agent。人物检索采用范围过滤、词项与时间排序，不是向量数据库。纠正让旧上下文失效；删除会清理相关对话。同步模型请求不能被线程强制取消；远端成功但本地未落盘时，恢复仍可能重复计费。

`engine.execute`、`store.py` 和前端状态管理仍较集中，后续按功能边界逐步拆分。安全预检只有有限规则；没有流式回复、邮件找回密码、付费订阅或自动模型训练。详见 [代码维护](maintenance.md)。

部署前完成 [deployment.md](deployment.md) 的门槛。部署材料、通过测试和服务器已购买，都不等于服务已公开上线。
