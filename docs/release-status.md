## 已知取舍

一个主 Agent 与固定工作流，不是多个自主 Agent。人物检索使用范围过滤、词项和时间排序，不是向量数据库。确认前不跨会话检索；纠正让旧上下文失效；删除采用清理相关对话的保守策略。同步模型请求不能被线程强制取消；检查点减少已完成阶段重复，但远端已处理、本地未落盘时仍可能重复计费。

安全预检只有有限规则，不能替代真实模型安全评测。没有流式输出、邮件找回密码、付费订阅、数据库 RLS 或自动模型训练。
