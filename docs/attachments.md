# 附件分析 v1

更新：2026-11-08。使用现有 Agent/Harness，不启动额外自主 Agent。

## 用户流程

1. 登录，在输入框旁选择“上传附件”。支持 UTF-8 TXT、带文字层的 PDF。
2. 点击“附件预览”，核对文字和说话人。PDF 表格、多栏或文字顺序可能提取不准。
3. 勾选本次要分析的文件，可选择一个相关人物；输入具体问题后发送。
4. 回答下方显示读取范围，“附件依据”可展开查看原文与位置。
5. 选定人物后，可从依据点击“确认记入人物”，编辑陈述及其类别后保存。
   每次回答最多保存一条来源记忆，之后在人物档案编辑。未确认不会自动写入人物记忆。

当前会话内，勾选会继续用于下一次提问；刷新或切换会话后需重新勾选。
没有勾选文件的消息仍按正常对话路由，不会自动读取所有附件。
这不表示抹去此前回答：此前已分析的内容仍可能存在于同范围、同版本的聊天历史中。

## 文件限制与读取范围

- 每份 2 MB；PDF 最多 40 页；提取文本最多 100,000 字符、3,000 个文字片段。
- 每次问题最多 3 份文件；每账号最多保存 20 份、原件合计 20 MB。
- 每账号每 10 分钟最多 20 次解析尝试，失败解析也计入。每服务进程最多并发 2 个解析器。
- 不支持 OCR、扫描件、图片上传、加密 PDF、Word、微信账号自动读取。
- 短文件在上下文预算内完整提供；长文件按中英文词项匹配选片段，保留原始顺序和位置。
  这是本地检索增强，不是语义向量检索；无匹配时按原顺序选取。
- 读取范围始终展示“选中片段数 / 全部片段数”。PDF 无文字页标为未读取，不能声称分析了图片。
- 第一版不提供超出上下文预算的全文分段汇总。要完整分析长文，请拆成较短文件；
  部分读取时，提示词要求说明限制，页面也独立显示范围。
- TXT 的日期、说话人标签按原文保留，不自动保证人物身份对应准确；名称不清时应澄清。

## 数据与权限

原文件以 base64 和提取文字一起保存到 `attachments` 表，外键归属账号和会话，
没有公开文件 URL，不写入静态目录。预览只渲染纯文本，不嵌入 PDF 脚本或外链。
模型收到的是本次选定文件的受限文字片段、相关人物背景和有限历史，原件不会直接发给模型。
学术搜索不会收到附件原文。附件里的指令不具有系统权限。

确认记忆会保留文件名、页码/行号和原始引文；用户编辑的是自己的陈述，
确认不代表外部事实已被核实。生成建议不自动升级成事实。

**删除附件会删除整个来源会话、会话中的其他附件和来源记忆**，界面操作前明确确认。
这样避免同一会话的旧回答、检查点继续携带文件内容。删除账号同样级联删除附件。
已传给模型的片段遵循模型服务商的数据保留规则；备份按运营者的保留与删除流程处理。
账号导出包含其原文件 base64；备份保持加密，不包含登录令牌。

## 代码路径

- `attachments.py`：TXT/PDF 提取、位置标记、词项检索及覆盖范围。
- `beta/attachments.py`：账号/会话访问、上传额度、文件保存、显式记忆确认。
- `beta/app.py`：上传、预览、删除和确认接口；上传独有 2.9 MB JSON 请求限制。
- `beta/service.py`：选择文件、冻结片段、绑定幂等键、上下文总预算。
- `engine.py`：`attachment_chat` 阶段沿用校验、检查点、Trace 和逐次调用预算。
- `schemas.py`：引用 ID 必须来自本次片段，quote 必须逐字存在，不能捏造引用。
- `prompts.py`：直接回答、说话人不确定性、限制指令注入、局部读取限制。

PDF 解析单独启动子进程：15 秒墙钟超时、10 秒 CPU；Linux 另有 512 MB 地址空间上限。
macOS 不支持同样的地址空间限制，因此依赖超时和输入上限。解析器不继承模型密钥环境。
这属于资源约束，不应宣传为能抵御所有解析库漏洞的完整安全沙箱。
依赖 `pypdf==7.0.0`；文字层和 OCR 的区别参见 [pypdf 官方文档](https://pypdf.readthedocs.io/en/stable/user/extract-text.html)。

## 升级与验证

安装依赖后启动：

```bash
.venv/bin/pip install -e '.[test,dev]'
.venv/bin/python persona_app.py --port 8770
```

数据库 v1 → v2 自动新增附件表，不删除旧账号和聊天。备份格式升为 v2，新版可读 v1/v2；
旧版不应读取新备份。升级前备份，回滚代码需配合升级前数据库副本，勿覆盖现有数据。
提示词版本更新为 `persona-5-attachments`，旧版本失败任务需要重新提交，不能混用语义恢复。

自动测试使用合成文件：PDF 文字层、加密/扫描件拒绝、超时、归属校验、CSRF、
请求大小、引用伪造、显式记忆、删除、备份恢复、迁移、上下文预算、失败恢复。
浏览器验收覆盖上传、预览、提问、引用展开、确认记忆、刷新及会话切换。
Mock 通过只证明工程链路；真实回复质量、公开部署仍需单独验收。
